# Development roadmap

1. **Scene and robot model** — completed in source; awaiting Webots installation and visual verification.
2. **Physics and movement** — four simulated drive wheels are connected to the controller; tune contact and braking after Webots is available.
3. **Interaction state** — floor/tabletop modes, stop, emergency-stop state, face states, and greeting are in the controller.
4. **Local voice and dialogue** — add microphone capture, local speech recognition, local dialogue, and local text-to-speech.
5. **Vision and pointing** — process camera frames during active dialogue, select marked targets, and reject ambiguous results.
6. **Pilot and trial logging** — define fixed pilot parameters, then run the 40 reported technical trials.
